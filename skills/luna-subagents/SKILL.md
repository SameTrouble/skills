# Luna 固定子代理策略

本策略适用于用户通过 `subagents-router` 选择本策略，或显式点名 `luna-subagents` 的任务。

## 模型配置

- 代码审查子代理由主代理直接派发，并继承主会话的模型与思考强度。
- 其他子代理固定使用模型 `gpt-6-luna` 和思考强度 `max`，不按任务类型或难度切换配置。
- 如果当前环境不能为其他子代理设置 `gpt-6-luna` + `max`，不要静默改用其他配置；说明限制，并由主代理继续，或询问用户是否切换策略。

## 委派与集成

- 只在委派能带来收益时使用子代理，单步小任务由主代理直接完成。
- 为每个子任务提供完成标准、必要背景、准确路径、修改范围和预期证据。
- 共享文件指定唯一写入者，或串行修改，避免多个子代理同时写入。
- 主代理负责拆分任务、协调依赖、整合结果并进行最终验收。
